#### Mixin Infrastructure

- Introduced `DirectInject` and `DirectExpression` to reduce unnecessary object allocations generated by Mixin injections. Thanks to MixinLite for the inspiration.
- Added `ConditionalMixin` support to conditionally apply mixins based on the runtime environment.
- Converted several existing mixins to the new injectors or `WrapWithCondition`, significantly reducing object allocation rates in certain extreme scenarios.

#### Rendering Compatibility

- Added Embeddium-compatible color blending for seasonal foliage rendering.

#### Distant Horizons

- Refactored `DHClientTool` and `DHTool`, based on the improvements proposed by zerastos in #185.
- Improved seasonal snow coloring and frozen-water handling for distant LODs.
- Reduced temporary object allocations and improved thread safety.
- Enabled seasonal DH LOD updates by default for new users. This option can still be disabled if it causes stuttering.
- Seasonal colors in the LOD biome cache are now updated even when seasonal DH LOD updates are disabled.

#### Other Changes

- Fixed incorrect heightmap usage in `BiomeHolder`, which could cause stuttering while loading chunks.
